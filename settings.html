🔄 跨裝置同步未設定

把進度存到你自己的 GitHub secret gist，電腦和手機就能共用。 免費、不會被搜尋到，token 只存在這台裝置，不會上傳到網站。

  1. 到 github.com/settings/tokens → Generate new token (classic) → 只勾 gist → 產生後複製
  2. 貼到下面按「開始同步」，這台裝置就會建立雲端備份
  3. 另一台裝置改用下面的設定碼，不用再產生一次 token

每次打開 App 會自動拉下最新進度，離開時自動上傳。 兩台裝置分開背的進度會合併，不會互相蓋掉。

📤 交給 Claude 處理

把你在這裡加的單字整包複製起來，貼到 Claude Code 對話裡， 就能請它補例句、改中文，或永久寫進網站資料檔（換手機也不會不見）。

💾 備份與還原

單字和學習進度都存在這台裝置的瀏覽器裡。清除瀏覽器資料會一起消失，記得偶爾備份。

🔊 發音–

單字和例句都用微軟神經語音事先錄好，每台裝置聽起來都一樣。 你自己新增的字沒有錄音檔，會自動改用裝置內建語音。

iPhone 開靜音模式時聽不到錄音檔，可以關掉靜音，或勾選上面這一項。
🔑 進階：讓 App 自己生成（選配）

平常不用填。填了 Anthropic API key 之後，「新增單字」頁會多一顆「直接自動生成」， 不用再複製貼上給 Claude。key 只存在這台裝置的瀏覽器，不會傳到別的地方。
